LH RAG GPT 개인정보 처리방침

시행일: 2026년 7월 3일

이 문서는 LH RAG GPT의 GPTs Actions API 사용과 관련하여 처리될 수 있는 정보와 이용 목적을 설명합니다.

LH RAG GPT는 사용자의 질문에 대해 법령, 행정규칙, LH 규정, 건설기준, 판례, 조달청 해석사례, 건설안전 사고통계 검색 결과를 제공하는 GPT 서비스입니다.

1. 수집 또는 처리하는 정보

본 서비스는 별도의 회원가입, 로그인, 결제 정보를 요구하지 않습니다.

다만 사용자가 GPT와 대화하면서 Actions 검색 기능을 사용할 경우, 검색 수행을 위해 다음 정보가 서버로 전달될 수 있습니다.

  • 사용자가 입력한 질문 내용
  • 검색을 위해 생성된 검색어 및 키워드
  • 법령명, 조문번호, 기준명, 판례 검색어 등 사용자가 입력하거나 GPT가 검색을 위해 구성한 정보
  • 건설안전 사고통계 진단을 위한 공종, 작업프로세스, 시설물 유형 정보
  • 서버 보안 및 장애 대응을 위한 접속 로그 정보(IP 주소, 요청 시각, User-Agent 등)

사용자는 주민등록번호, 연락처, 주소, 계정정보, 비밀번호, 내부 비공개 문서, 기타 민감정보 또는 기밀정보를 입력하지 않는 것이 좋습니다.

2. 이용 목적

수집 또는 처리되는 정보는 다음 목적에 한해 사용됩니다.

  • 사용자의 질문에 적합한 검색 결과 제공
  • 법령, 규정, 기준, 판례, 해석사례, 사고통계 조회
  • 서비스 오류 확인 및 품질 개선
  • 과도한 요청, 오남용, 보안 위협 방지
  • 서버 운영 및 장애 대응

3. 외부 서비스 및 제3자 제공

본 서비스는 검색 결과 제공을 위해 다음 외부 서비스 또는 인프라를 사용할 수 있습니다.

  • OpenAI ChatGPT: 사용자의 대화 및 GPT Actions 호출 처리
  • Fly.io: API 서버 호스팅
  • 국가법령정보센터 등 공공 Open API: 법령, 행정규칙, 판례 등 공개자료 조회
  • 임베딩 또는 의미검색 제공업체: 의미검색 처리를 위한 질의문 임베딩 생성이 필요한 경우

본 서비스는 사용자의 질문 내용을 광고 목적으로 판매하거나 제3자에게 임의로 제공하지 않습니다.

4. 보관 기간

본 서비스는 별도의 사용자 계정을 운영하지 않으며, 검색 요청 내용을 영구 보관하는 것을 목적으로 하지 않습니다.

다만 서버 운영, 장애 대응, 보안 확인을 위해 접속 로그 및 오류 로그가 일정 기간 보관될 수 있습니다. 보관 기간이 지나거나 운영상 필요가 없어진 로그는 삭제하거나 식별이 어렵도록 처리합니다.

OpenAI ChatGPT에서의 대화 저장 및 이용은 OpenAI의 개인정보 처리방침과 사용자의 ChatGPT 계정 설정을 따릅니다.

  • HTTPS 기반 통신 사용
  • 불필요한 개인정보 입력 제한 안내
  • 서버 요청 크기 제한 및 과도한 요청 방지
  • 운영상 필요한 범위 내에서만 로그 확인
  • API 키 등 비밀정보의 서버 환경변수 관리
