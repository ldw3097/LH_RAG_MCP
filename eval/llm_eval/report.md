## 4. 조건A(웹검색) 실패 분석

### 패턴 1 — LH 내부 규정 접근 불가 (lh 전 문항)
LH 복지후생규정·여비규정·경영계획규정·임원추천위원회규정은 LH 내부 문서로 웹에 공개되지 않음.
→ lh 카테고리 5문항 전부 "내부 문서 확인 요망" 응답 또는 환각 수치 제시. 정답률 **0%**.
- lh-04: "일반적으로 2배수 또는 3배수"로 잘못 추측 (실제: 3~5배수)
- lh-02: "편도 12km 또는 20km"로 잘못 추측 (실제: 왕복 80km 미만)

### 패턴 2 — 출처 부재로 세부 조건 누락 (law, pps)
큰 방향은 맞으나 조문의 구체적 조건(장기계속공사 제1차 계약 체결일, 면제 시 국고귀속 등)을 놓침.
→ law 5문항 전부 부분정답 이하, pps 4/5 부분정답 이하.

### 패턴 3 — 기술 용어 혼동 (kcsc-02)
"1.5m 이상의 깊이" 기준을 "폭 1.5m 이상"으로 오독하여 핵심 사실 오류.

### 패턴 4 — 판례 법리 일부 누락 (prec)
기본 법리는 알고 있으나 판결에서 추가로 확인된 세부 판시사항 누락
(예: prec-01에서 직권조사사항·상고심 주장 가능 부분 미언급).

## 6. 소견 및 파일럿 품질 평가

### 문항 품질
- 25문항 전부 검증 통과(탈락 0건). gold_answer·source_quote가 실제 원문으로 뒷받침됨.
- 질문의 자립성·사실형 요건 충족. LH 실무자가 묻는 형태로 자연스럽게 작성됨.
- KCSC 케이스는 시방서 코드 수준의 세부 질문으로, 전문 지식 없이는 답하기 어려운 유형 포함.

### 채점 품질
- 3단계(정답/부분/오답) 채점이 일관되게 적용됨.
- "방향은 맞으나 세부 누락"을 부분정답으로 정확히 구분. 과도한 추가 정보를 오답 처리하지 않고 핵심 일치 여부로 판정.
- 블라인드(X/Y) 설계로 MCP 사용 여부가 채점에 영향을 주지 않음.

### 한계 (전체 실행 시 유의)
1. **n=25 파일럿** — 카테고리당 5문항으로 통계적 신뢰도 제한. 전체 500문항 실행 시 CI 산출 필요.
2. **law/prec 구조적 유리** — 정답 근거를 MCP로 확보했으므로 조건B가 구조적으로 유리. 단, "MCP가 근거 문서를 가져오는가"가 바로 검증 대상이므로 평가 목적에 부합.
3. **채점자 편향** — Claude가 채점자이므로 Claude 스타일 답변을 선호할 가능성. 향후 인간 검토 10건 샘플링 권장.
4. **kcsc 격차(+40pp)** — 상대적으로 작음. 공개된 KCSC API 원문이 웹에서도 일부 검색 가능하기 때문으로 추정. 더 복잡한 시방서 조항 포함 시 격차 확대 예상.

## 7. 전체 실행 권고사항

파일럿 결과 파이프라인 동작 정상, 채점 품질 양호. **전체 500문항 실행 권고.**

전체 실행 시 추가 고려:
- kcsc 문항: 단순 수치 외에 계산·판단이 필요한 문항 비중 확대
- prec 문항: 동일 법리를 다루는 복수 판례 중 최신 판례 검색 성공 여부 검증 문항 포함
- 조건A 추가 세분: "웹검색 없음(순수 지식)" 조건도 추가하면 MCP vs 웹검색 기여분 분리 가능
