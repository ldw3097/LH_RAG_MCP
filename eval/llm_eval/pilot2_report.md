## 2. 카테고리별 소견

### lh (LH 규정): Δ = +100pp ★ 최대 효과
- 조건 A **전패** — 웹에서 LH 내부 규정 수치를 찾을 수 없어 모두 무응답·오답.
- 조건 B **전승** — MCP가 내부 문서를 직접 검색해 정확한 수치·기간·요건 제공.
- **MCP의 핵심 가치**: 웹에 공개되지 않은 사내 규정이 주 타깃일 때 MCP 없이는 답 불가.

### kcsc (건설기준): Δ = +60pp
- 조건 A는 일반 웹검색으로 건설기준 수치를 거의 찾지 못함 (기준 문서 비공개).
- **kcsc-03 오류 (A 부분정답, B 오답)**: 질문은 KCS 61 20 20의 "30m 이내" 기준을 물었으나
  조건 B가 LHCS 11 50 15 05의 "6m" 기준을 반환. 서로 다른 표준 간 유사 내용 혼동 → 검색 정밀도 개선 필요.
  - A는 우연히 "30m"를 알았지만 표준명을 특정하지 못해 부분정답.
  - B는 "6m"를 자신있게 제시해 오답.

### pps (조달청 해석사례): Δ = 0
- 조건 A·B 모두 100% — 조달청 계약법규 해석은 법제처·나라장터 등 공개 경로에서도 접근 가능.
- MCP 부가가치 낮음. 단, 최신 비공개 사례는 MCP 우위 가능.

### law (법령): Δ = +40pp
- 조건 A 60% — 주요 법령 조문은 국가법령정보센터 등 공개 웹에서 접근 가능.
- 조건 A 실패 2건은 **법령 적용 세부 기준**(승인권자 구분·재하도급 원칙 예외) 혼동 → 조문 맥락 파악에서 MCP 우위.
- 법령 영역은 A의 기본 성능이 높아 Δ 낮음.

### prec (판례): Δ = 0
- 조건 A·B 모두 100% — 판례 요지는 종합법률정보(대법원) 등 공개 웹에서 접근 가능.
- MCP `search_precedents`는 키워드 AND 매칭 특성상 법원 공개 DB 대비 차별화 낮음.
- **[2026-06-28 업데이트]** 전체 100문항 평가에서 구버전 툴 B 64%로 하락 확인 → 다중 키워드 병렬 검색 + DeepInfra 리랭커로 개선 후 재평가 시 **93%** 달성 (A=72% 상회).

## 3. 주요 발견

### 3-1. MCP 효과는 카테고리별로 극명하게 다름
| 유형 | MCP 효과 | 이유 |
|---|---|---|
| **LH 규정** | 극대 (+100pp) | 비공개 사내 문서 — 웹으로 접근 불가 |
| **건설기준** | 대 (+60pp) | 전문 기준 문서 — 웹에 체계적으로 공개 안 됨 |
| **법령** | 중 (+40pp) | 공개 웹에 있지만 세부 해석에서 MCP 유리 |
| **조달청** | 없음 (0pp) | 공개 DB에서도 접근 가능 |
| **판례** | 없음 (0pp) → **+21pp** *(개선 후)* | 파일럿 샘플 편향; 전체 100문항에서 툴 개선 후 A=72% → B=93% |

### 3-2. 검색 정밀도 문제 (kcsc-03)
- MCP가 **비슷한 내용의 다른 표준**을 검색해 오답 생성.
- KCS 61 20 20(콘크리트 타설·양생)과 LHCS 11 50 15 05(구조물 보호 복토) 혼동.
- 개선 방향: 질문에 표준 코드를 명시하거나, 시방서 유형 필터 추가.

### 3-3. WF-2 오염 검사 통과
- 조건 A 25건: MCP 툴 사용 0건 확인.
- 조건 B 25건: 카테고리별 MCP 툴 1회 이상 사용 확인.

## 6. 결론 및 권고

1. **MCP 유용성 확인**: 전체 평균 +40pp 향상. 특히 LH 규정(+100pp)·건설기준(+60pp) 영역에서 MCP 없이는 실질적 답변 불가 — LH 직원 사용 시나리오에 부합.
2. **kcsc 검색 정밀도 개선 필요**: 유사 표준 혼동 문제 확인 → 표준 유형 필터 또는 프롬프트 개선.
3. **pps·prec 재검토**: 공개 데이터와 차별화 없는 영역 — 더 특수한 질문(최신 사례, 비공개 해석 등)으로 질문 재설계 시 MCP 효과 더 뚜렷해질 것.
4. **전체 실행 권고**: 파일럿 워크플로 정상 작동 확인. 전체 500문항 실행 시 `scripts/eval_sample_full.py` → WF-1(law/prec 시드 100개 분량) → WF-2 → WF-3 순으로 진행 가능.
